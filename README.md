## What is this?

A small Windows utility that helps you get through the **Automaton Attack** mini-game in **Dota 2**. It works as a macro: it quickly types English letters until the game registers the correct ones. No OCR or text recognition is used, so there is nothing extra to install.

> [!NOTE]
> The macro only works while wrong key presses in the mini-game are not penalized. If the rules change, it may stop helping.

## 🚀 How to use

1. Download the archive using the link above.
2. Extract it. The password is `2026`.
3. Run the extracted file.
4. Launch Dota 2 and open Automaton Attack.
5. Switch your keyboard layout to English: `Win + Space` → `ENG`.
6. Press `F8` to start the macro.
7. When the mini-game ends, press `F8` again to stop.

## 🛠 Troubleshooting

<details>
<summary><b>My antivirus blocks the file</b></summary>

Macros that simulate keyboard input are often flagged as suspicious by mistake. If you do not trust the file, do not run it. Scan it on VirusTotal first, and only add an exclusion if you are sure about the source.

</details>

<details>
<summary><b>Dota 2 does not accept the letters</b></summary>

- Make sure the Dota 2 window is active.
- Switch to the English keyboard layout.
- Run the macro and the game with the same privileges (both as a normal user, or both as administrator).
- Restart the macro and try again.

</details>

<details>
<summary><b>F8 does nothing</b></summary>

On some laptops the function keys also control volume or brightness. Try `Fn + F8`.

</details>

<details>
<summary><b>Letters are typed into the wrong window</b></summary>

Press `F9` immediately. Always stop the macro before leaving the mini-game.

</details>

## ❓ FAQ

**Do I need to install Python?**
No. Just download the file and run it.

**Does it work on Windows 10 and 11?**
Yes, both are supported.

**Can I get banned?**
The macro does not touch the game's memory or modify any Dota 2 files. It only simulates key presses. Still, any kind of automation is used at your own risk, and Valve's rules or the mini-game itself may change.
